Source: Voltagrid status list export, 74 units. Open items are counted per unit from the Handover Status, Testing Start Status and CAT Outstanding Items columns, with spelling variants merged (for example “PT cover missing” and “PT covers not installed”). A stage only counts a unit once it has that stage’s date. Where a stage is blank for a unit that has reached it, it is counted as zero open items; “Same as handover” entries copy the handover list.
